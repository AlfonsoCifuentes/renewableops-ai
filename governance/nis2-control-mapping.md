# NIS2 — mapeo de controles de ingeniería

| Tema | Implementación demostrable | Brecha para producción |
|---|---|---|
| Riesgos | registro versionado y owners | proceso corporativo y apetito formal |
| Incidentes | severidades, playbooks, evidencia | SOC/CSIRT y plazos legales |
| Continuidad | snapshots históricos y rollback | RTO/RPO contractual y restore real |
| Supply chain | lockfiles y scans | evaluación continua de proveedores |
| Secure development | CI, lint, tests, threat model | SDLC corporativo y pentest |
| Criptografía | TLS/Key Vault de referencia | PKI y rotación operada |
| Access control | servicios locales, RBAC cloud | IdP, MFA, PAM y recertificación |
| Monitoring | Prometheus/Grafana/Loki | SIEM central y cobertura 24/7 |

Este cuadro demuestra alineación de diseño; no declara cumplimiento NIS2.
