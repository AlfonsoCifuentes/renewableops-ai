# Dashboard

El control room tiene 13 rutas: Overview, Fleet, Asset Health, Forecast Solar,
Forecast Wind, Market, Visual Inspections, Data Explorer, Data Quality, MLOps,
Observability, Governance y Scenario Lab.

Los filtros globales se guardan en la URL. Los datos llegan desde un snapshot
versionado y saneado, por lo que la demo puede ejecutarse sin credenciales.
Todas las gráficas llevan nombre accesible, la navegación funciona por teclado,
el movimiento reducido se respeta y el layout se adapta a 390 px.

Diseño: lienzo marfil, tinta verde, acento óxido, tipografía editorial y
densidad de control room. No usa gradientes, glow, neón ni glassmorphism.
