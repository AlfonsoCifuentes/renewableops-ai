# Texto para CV y entrevista

**CV:** Diseñé RenewableOps AI, una plataforma reproducible de operaciones para
12 activos renovables con lakehouse Pandas/PySpark, forecasting probabilístico
sklearn, anomalías, visión HOG/LBP, FastAPI/Next.js, MLflow, n8n,
Prometheus/Grafana y un bundle Databricks con Lakeflow, Unity Catalog y AI/BI;
incorporé contratos, lineage, aliases Champion/Challenger, rollback,
threat-model y Terraform Azure cost-guarded.

**Respuesta corta:** El dataset local no necesita Spark; lo usé para demostrar
paridad de transformaciones y el camino de gobierno/escala. Nunca entrené con
un split aleatorio temporal, ni presento el modelo como controlador de planta.
